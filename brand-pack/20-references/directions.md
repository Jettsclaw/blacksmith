# Blacksmith — structural directions (v1, seeded 2026-07-07)

> The anti-generic layer. Every pre-plan picks ONE direction and must differ from the
> last entry in `build-log.md`. The ban is never external references — it is reskinning
> our own previous build. Refresh with refero pulls each quarter; directions are
> starting grids, not templates to trace.

## D1 — "Dark editorial flagship" (the S6 selling-sequence site — the shipped default)
Near-black canvas, full-bleed real shop photography, Oswald uppercase display, gold
eyebrows/CTAs, 8-section selling sequence per `site-strategy.md` (hero → shop story →
services triptych → proof → gallery → Circle reveal → visit → footer). "Book a Cut"
= gold main CTA → `#book` in-site chat (sticky bottom bar was removed site-wide,
Beau 2026-07-07 — don't re-add). Refs: our live `site/index.html`, premium hospitality sites (e.g.
blindbarber.com, dark editorial restaurant sites on refero). Use for: main site pages,
arm pages (Academy, Barbers, Visit). NOT for pure Circle conversion (the reveal is one
section here, not the whole job).

## D2 — "Founding letter" (Circle sales page / PDF — Hormozi lead stack, human-close)
Long-form single column, reads like a letter to a regular, not a store. Identity-first
tier stack (The Cut / The Club / The Empire, "The" always), value stack from
`offer.md` (locked slot → lounge → wall → merch → gifting → events), real founding
scarcity (first 30/75/100, stated plainly), walk-in vs member contrast table, exactly
ONE CTA ("Claim your founding number" / "Lock in your chair") that books the CALL —
the page pre-qualifies, Jett closes. Refs: acquisition.com workshop page anatomy,
premium members-club sites (Soho House application pages). Use for: Circle landing
page, Circle PDF (via pdf-composer), VIP call-sheet leave-behind.

## D3 — "One line, one mark" (poster / print / in-shop)
Near-black stock, the real logo mark, ONE signature line in Oswald uppercase
("Your chair. Your barber. Every time."), gold keyline or single gold word, QR to
the site's `#book` chat or the Telegram wait-bot or Circle. Nothing else — the room
does the talking. Print variant may invert
to logo-black.png on light stock. Use for: in-shop posters, mirror decals, counter
cards, Members Wall signage. Judge checks it reads from 3 metres.

## D4 — "The counter voice" (booking-bot + conversational copy)
Not a layout — a voice spec for the booking/walk-in chat (site widget + Telegram
wait-bot) and SMS. This IS the booking path now (SLIKR links are gone; SLIKR feeds
data backend-only, and the name never appears to customers). Talks like the bloke at
the counter: short, plain, knows your name. "Zayn's got a chair at 2:40. Want it?"
— never "Your appointment has been successfully scheduled!". Real wait times/slots
from the live feed, never invented. Bot + web chat copy stays word-for-word aligned
(the shipped parity rule). No emoji hype, no exclamation marks, no
corporate apology-speak. Every message ends with the next physical action (time, chair,
name). Use for: wait-bot replies, booking confirmations, reminder SMS, queue updates.

---
Rule of thumb: site/arm pages → D1, Circle conversion → D2, print/in-shop → D3,
bot/SMS → D4. Two consecutive builds on the same direction = fail unless different
ASSET TYPES, and the pre-plan must cite how they differ in hero object + section order.
